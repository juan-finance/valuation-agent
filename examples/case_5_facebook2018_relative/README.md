# Case 5: Facebook (2018), relative valuation
- Files: Facebook 2018.docx (REFERENCE for method only). No Excel.
- Technique: relative valuation (multiples, regression, interpretation)
- Currency: USD
- Valuation date: 2018 (from the case name). Confirm the exact date in the Word document and
  write it in outputs/<ticker>_<date>/case_summary.md.
- Use in stage: 3
- What it teaches: how the most relevant multiples are chosen for a high-growth technology
  firm, how peers are selected, how the regression on multiples is run and read, how the
  implied value is derived, and how the result is interpreted.
- KNOWN LIMITATION: the solution underestimated the growth that Facebook actually achieved.
  Use this case for method and structure only. Do NOT use it as evidence for the right
  growth level or the right valuation level. For high-growth companies, compare the growth
  implied by the multiples with analyst estimates and the annual report narrative, and do
  not anchor on historical growth alone.
- Relevance: none of the 20 companies is a technology platform. The multiples used here (for
  example per-user metrics) will not carry over. Learn the process of choosing and justifying
  multiples, not the multiples themselves.
- Dated inputs: market multiples, peer data and rates belong to 2018. Never reuse the numbers.
