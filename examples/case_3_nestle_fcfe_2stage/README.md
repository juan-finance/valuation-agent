- Technique: FCFE (free cash flow to equity) with a stable debt ratio, 2-stage growth
- Currency: CHF (Swiss franc)
- Valuation date: not recorded. Read it from professor_solution.docx and write it in
  case_summary.md. Do not assume a date.

  equity is built in a non-euro currency, and how the value per share is obtained.
