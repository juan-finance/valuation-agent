# Method guides
Original instruction documents from which the methodology/ procedures were built:
- Steps in Company Valuation.docx: DCF procedure (encoded in methodology/dcf_procedure.md).
- Agent Instructions Comparables Company.pdf: peer selection and multiples (comparables_procedure.md).
- Agent Instructions Regression-Based Relative Valuation in Excel.pdf: regressions (regression_procedure.md).

They were written from the professor's lecture notes (lecture_notes/), which outrank them: if a
lecture contradicts one of them, the lecture wins. They also rank BELOW the methodology
procedures: the procedures already contain these documents' content and deliberately correct
their errors and internal contradictions (conflict registers: dcf_procedure.md section 11,
regression_procedure.md section 11). Those corrections stand; never use these originals to undo
them. Execution normally uses the Markdown procedures. Open these files only to settle a doubt
the procedures leave open, and record the outcome. Full hierarchy: .agents/skills/company-valuation/SKILL.md.
